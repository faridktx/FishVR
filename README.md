# FishVR

FishVR is a Unity VR prototype built using the **XR Interaction Toolkit** where players use a harpoon launcher to shoot expanding nets to capture objects.

## Current Features

- VR grab interaction using XR Interaction Toolkit
- Harpoon launcher that fires a net projectile
- Net expands while flying
- Physics-based projectile with gravity
- Collision handling for projectile spawn
- Prefab-based projectile system

## Controls

| Action           | Control             |
| ---------------- | ------------------- |
| Grab Harpoon Gun | Controller Select   |
| Fire Net         | Controller Activate |
